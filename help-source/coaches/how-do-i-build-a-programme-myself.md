1. Add a client, or open one and tap **Build programme**.
2. On the **Programme** step, choose **Blank**.
3. Set the days per week.
4. Tap a day to add exercises, then set sets, reps and rest for each.
5. Drag **⋮⋮** to reorder. To group exercises together, merge them into a superset.
6. Tap **Continue**, then check the **Review** step.

## Good to know

- Warm-ups and cool-downs are added for you.
- To reuse this programme for other clients, save it as a template. See [How do I start from a template?](/help/coaches/how-do-i-start-from-a-template)
